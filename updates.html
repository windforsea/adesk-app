ADesk 업데이트 내역

배포된 버전의 추가 기능, 개선 사항과 오류 수정을 안내합니다. 앱 안에서도 새 버전을 확인하고 바로 업데이트할 수 있습니다.

2026년 11월

0.6.1 · 2026-11-26 최신 배포

  • 개선 테스트 옵션을 끈 프로젝트에서는 AI가 계획서에 테스트 작업을 넣지 않고, 위임받은 AI가 받는 안내에도 검증 명령 줄이 붙지 않습니다. 테스트 작업은 옵션이 켜졌거나 사용자가 요청할 때만 넣습니다.
  • 개선 AI가 프로젝트 맵(adk/mapping.adesk.md)을 고칠 때 앱의 맵 양식 지침(data/guides/map-format.md)을 받습니다. 새 프로젝트의 맵 머리말에도 지침 안내가 들어갑니다.
  • 오류 수정 Antigravity가 「You have exhausted your quota on this model.」 오류로 작업을 끝내도 한도 소진으로 알아보지 못하던 문제를 고쳤습니다.
  • 오류 수정 화면 언어를 바꾸면 새 방의 제목 칸에 다른 언어의 기본 이름(「새 대화」·「New chat」)이 보이던 문제와, 영어 화면에서 만든 방에 첫 답변 뒤 제목이 붙지 않던 문제를 고쳤습니다.

0.6.0 · 2026-11-26

  • 추가 설정 › 화면에 언어 선택(한국어·English)을 넣었습니다. 저장한 언어가 없으면 운영체제 언어가 한국어일 때 한국어, 그 밖에는 English로 시작합니다. 언어를 바꿔 저장하면 같은 창에서 화면을 새 언어로 다시 엽니다. 화면 문구, 작업·계획·프로젝트 알림, 설정 저장 오류, CLI 설치·로그인 안내, 사용량 안내, 앱 설치·업데이트 문구가 고른 언어로 나옵니다. 이전 한국어 대화와 QA 기록도 그대로 읽습니다.
  • 추가 AI가 설정 언어로 답합니다. 대화·토의 답변, 도구 사용 전 진행 안내, 단계 보고의 요약·질문·남은 문제, 테스트 수정 판정의 반려 사유가 대상입니다. 언어를 바꾸면 이어 가는 대화 세션도 다음 호출부터 새 언어를 따릅니다. 영어에서는 사용자를 이름만으로 부릅니다. 이름을 정하지 않고 첫 프로젝트를 만들면 이름이 화면 언어에 맞게(영어는 「User」) 저장됩니다.
  • 추가 계획서와 작업 보드를 영어 키(## Step 1.·- Files to Change:·## Decisions 등)로도 읽습니다. 영어 설정에서는 AI가 영어 키로 계획서를 쓰고, 새 작업 보드의 제목과 단계 줄도 영어로 만듭니다. 승인 때 넣는 결정 줄은 그 계획서의 키 언어를 따르고, 한 계획서에 두 언어 키가 섞이면 승인을 멈추고 알립니다.
  • 개선 대화 입력창이 2줄로 시작해 글이 늘면 10줄까지 위로 늘어납니다. 좌측 아래 설정 줄을 없애고 대화 목록 머리줄의 톱니 아이콘으로 옮겼습니다.
  • 개선 대화 목록 아래의 실행 중 CLI 칸을 없앴습니다. 실행 상태는 방 카드의 점으로 보이고, 접은 프로젝트나 목록에 없는 방의 실행은 프로젝트 머리줄의 점(5개 넘으면 +N)으로 보입니다. 보관한 방도 실행 중이면 목록에 보입니다. 실행 멈추기는 방을 연 뒤 대화 화면 아래 상태 줄의 ×로 합니다.
  • 개선 완료·질문·반려 중계가 도는 동안 같은 AI에게 보낸 메시지가 중계 AI에게 바로 전달되고, 그 답이 중계 메시지로 방에 올라옵니다. 중계 AI가 백그라운드 명령을 기다리는 동안에도 끝난 답이 먼저 올라옵니다. 판정 뒤에 보낸 메시지는 중계가 끝난 뒤 새 실행으로 갑니다.
  • 개선 구현이나 중계가 진행 중이어도 전용 사용량 카드(예: Fable)로 보낸 메시지는 그 카드의 모델로 바로 새 실행을 엽니다. 전에는 같은 AI의 중계에 묶여 대기하거나 기본 모델로 실행됐습니다.
  • 개선 단계가 끝날 때 앱이 하던 구문 검사와 줄 수 경고를 없앴습니다. 테스트를 끄면 구문 오류로 단계를 실패 처리하지 않고 「완료 검사 안내」도 붙지 않습니다. 테스트를 켜면 검증기가 검사합니다.
  • 오류 수정 Codex가 답을 끝낸 순간의 알림이 가끔 사라져, 답이 있는데도 「CLI가 빈 응답 또는 유효하지 않은 출력을 반환했습니다」로 실패하던 문제를 고쳤습니다.
  • 오류 수정 새 대화방의 첫 메시지에 AI가 방 제목만 답하고 끝나던 문제를 고쳤습니다. 제목을 맡은 AI는 요청에 먼저 답하고 답변 끝에 제목을 덧붙입니다.
  • 오류 수정 AI가 일하는 중에 보낸 메시지 카드에 내부 코드(turn_boundary 등)가 보이고, 실행이 끝나면 다시 보내는 정상 대기도 「전달 실패」로 보이던 문제를 고쳤습니다. 대기 이유는 「턴이 바뀌는 중」처럼 문구로 보입니다.
  • 오류 수정 백그라운드 명령을 멈춘 뒤 Claude에게 다시 말을 걸면 기존 대화 세션이 이어지지 않던 문제와, 메시지 카드를 끌어 복사하면 머리글의 @이름이 함께 복사돼 고른 카드가 무시되던 문제를 고쳤습니다.
  • 오류 수정 중계가 도는 동안 보낸 메시지가 중계 뒤 실행될 때 [재개]가 상태 불일치로 막히던 문제를 고쳤습니다.
  • 오류 수정 Claude가 답하는 중에 덧붙인 메시지를 이어서 처리하는 동안 방 목록의 실행 표시와 답변 아래 진행 줄이 사라지던 문제와, 대화 카드 안의 긴 경로가 카드 밖으로 넘치던 문제를 고쳤습니다.

0.5.0 · 2026-11-25

  • 개선 대화 기록(chat.md)의 숨은 정보를 같은 폴더의 chat.meta.jsonl로 옮겨, AI가 읽는 대화 기록이 작아집니다. 기존 기록은 프로젝트를 처음 열 때 자동으로 옮기고, 옮기기 전 원본을 adk/chat/runtime/backups/v7-시각/에 백업합니다. 백업은 「실행 기록 보관 일수」가 지나면 지웁니다. 옮긴 기록은 0.4.x에서 열 수 없으므로 이전 버전으로 되돌리지 마세요.
  • 추가 대화 위에 「할 일」 칸을 두었습니다. 승인을 기다리는 작업 신청, 질문 답변 안내, 테스트 수정 판정, 결과 수락과 다시 하기, 다음 단계 선택을 이 칸에 모읍니다. 대화 목록에는 「승인 대기」·「승인됨」·「신청 취소」 같은 기록 줄과 보고 기록만 남습니다. 사람의 답을 기다리는 질문 보고는 오래되어도 대화 목록에 남습니다.
  • 추가 할 일 칸의 카드는 펼친 채 뜹니다. 카드를 접거나 펼치면 그 상태를 카드 종류별로 저장하고, 같은 종류의 새 카드는 앱을 다시 켜도 저장한 상태로 뜹니다.
  • 추가 할 일 칸과 대화 목록 사이의 경계선을 끌어 할 일 칸 높이를 바꿀 수 있습니다. 줄인 높이는 큰 카드의 상한이 되고, 아래 끝까지 끌면 상한이 풀립니다. 높이는 앱을 켠 동안만 기억합니다. 끌지 않으면 긴 신청 카드도 내용만큼 커지고, 대화 목록은 본문 약 4줄 높이를 남깁니다.
  • 개선 새 계획 신청이 들어오면 같은 프로젝트의 다른 계획서 승인 대기 신청을 자동으로 취소합니다. 같은 계획서를 다시 신청하면 앞 신청은 「개정됨」으로 닫힙니다. 신청 카드의 「반려」 버튼은 「취소」로 바꿨고, 승인 전에 취소한 기록은 「신청 취소」로 보입니다.
  • 개선 채팅창 아래 실행 상태 줄이 왼쪽 CLI 목록과 같은 때에 같은 상태를 보입니다. 구현 보고 뒤 중계 AI가 검토하는 동안에도 중계 줄과 도구 활동이 보입니다. 구현 중 중계 AI의 대화와 중계 호출이 맡긴 위임도 줄로 보입니다. 줄의 ×는 왼쪽 목록의 ✕와 같은 대상을 멈춥니다. 같은 프로젝트의 다른 방에 다녀와도 마지막 도구 활동이 보입니다.
  • 개선 상태 줄이 첫 도구를 부르기 전과 도구가 끝난 뒤에 「생각 중」을 보이고, 실패한 도구는 「실패 · 원래 글」로 보입니다. Claude의 웹 검색·웹 읽기·하위 작업·스킬, Antigravity의 파일 읽기·수정·명령 실행·웹 검색을 한국어 활동 이름과 파일명·명령·검색어로 보입니다. ;·|·&&로 이은 명령 안의 검색 명령도 「검색」으로 보입니다.
  • 개선 실행 보고 카드의 접는 칸을 한 모양으로 맞췄습니다. 토큰 비용 칸은 접혀 있어도 제목 줄에 합계 금액을 보입니다. 맵 점검 칸(행 미갱신 후보·맵 행 없는 새 파일 등)은 처음에 접혀 있고 경로를 한 줄에 하나씩 보입니다. 커밋 파일·시작 전 변경·test 수정·맵 점검 칸은 펼침 상태를 칸마다 기억합니다.
  • 개선 대화 카드의 오류·주의를 색이 다른 상자로 보입니다. 통과한 검사는 「검사 N개」 칸에, 실패한 검사는 결과 경고 상자에만 보입니다. 「보고 원문 전체」 칸은 보고 형식 오류일 때만 보입니다. 계획의 마지막 결과 보고에 「계획 완료」를 보입니다.
  • 개선 계획서를 붙인 메시지의 「작업 신청」 표시를 없애고 버튼 이름을 「계획서 보기」로 바꿨습니다. 「Git 확인 필요」 상자에서 「시작 전 변경 있음」 칸과 겹치는 줄을 뺐습니다.
  • 개선 단계 시작 전부터 커밋하지 않은 수정이 있던 파일에서 실행 AI가 자기 줄만 올리면, 시작 전 수정은 작업 폴더에 남고 단계 커밋에 들어가지 않습니다. 단계 시작 안내에 그런 파일 목록과 자기 줄만 올리는 방법을 넣었고, 자기 줄만 올린 파일에는 「시작 전 변경 있음」 경고를 띄우지 않습니다.
  • 개선 구현이 끝난 뒤 지난 작업 기록을 따로 정리해, 중계 시작과 화면 갱신이 정리를 기다리지 않습니다. 「실행 기록 보관 일수」가 0이어도 끝난 지 20분이 안 된 작업 로그와 백업은 남깁니다(방을 삭제하면 바로 지웁니다). 바로가기 폴더(링크·정션)가 든 오래된 기록 폴더도 지우며, 바로가기가 가리키는 대상은 건드리지 않습니다.
  • 개선 Antigravity Argon의 주간 한도가 Gemini 공용 한도로 합쳐져 Argon 전용 사용량 카드를 없앴습니다. Argon 사용량은 Gemini 공용 사용량으로 계산합니다.
  • 개선 창 위쪽 제목줄을 40px에서 34px로 줄이고, 제목줄과 대화 목록·대화·블랙보드 패널 사이에 6px 간격을 두었습니다. 할 일 칸과 대화 목록의 카드 폭을 같게 맞췄고, 잘린 카드도 모서리를 둥글게 보입니다. 결정 직접 작성·추가 지시사항·다시 하기 입력 칸을 같은 모양으로 맞췄습니다.
  • 오류 수정 Antigravity 1.5.15 대화에서 오래 걸리는 백그라운드 명령을 기다리다 출력이 10분 없으면 대화가 끊기던 문제를 고쳤습니다. 이제 「백그라운드 대기」로 보이고 최대 60분 기다립니다.
  • 오류 수정 사용자가 직접 멈춘 실행과, 멈춘 뒤 다른 대화가 이어진 실행에도 「재개」 버튼이 보이던 문제를 고쳤습니다. 이제 오류나 앱 재시작으로 멈췄고 그 방의 마지막 대화일 때만 보입니다.
  • 오류 수정 동봉 검증기가 테스트를 하나도 실행하지 않은 단계를 「통과」로 보이던 문제를 고쳤습니다. 이제 「미실행」으로 보입니다. 테스트 단계가 정상 종료했어도 결과 요약을 읽지 못하면 실패로 처리하고 로그 경로를 보입니다.
  • 오류 수정 드롭다운의 선택값과 ▼가 칸의 세로 가운데에 오지 않던 문제를 고쳤습니다. 설정 [작업] 탭에서 쓰이지 않던 「PC 이름」 칸을 없앴습니다.

0.4.1 · 2026-11-23

  • 추가 앱 하단의 커피잔 버튼과 배포 사이트의 「후원하기」 링크에서 카카오페이 후원 QR을 볼 수 있습니다. 작업 중에는 커피잔이 15분마다 차오르고, 한 시간마다 휴식 안내가 나타납니다. 커피잔에 마우스를 올리면 작업 시간을 볼 수 있습니다. PC가 절전 등으로 5분 넘게 쉬면 작업 시간을 다시 셉니다.
  • 추가 대화 메시지의 코드 박스에 마우스를 올리면 오른쪽 위에 복사 버튼이 나타납니다. 누르면 박스 안 내용만 복사합니다.
  • 개선 답변 아래 이미지 썸네일 모음에 프로젝트에 실제로 있는 이미지만 보입니다. 예시 파일 이름처럼 찾지 못한 경로에 「없음」 칸을 만들지 않습니다.
  • 개선 업데이트와 설치 파일을 GitHub에서 내려받습니다. 이 버전으로 업데이트하면 다음 업데이트부터 새 배포 주소를 확인합니다. 배포 사이트도 GitHub로 옮겼습니다.
